====================================================================
 Buckshot Roulette —— 黑色霰弹模组 (Black Shell Mod) v1.0
====================================================================

【效果】
  * 新增第三种霰弹：黑色霰弹。
  * 打自己   → 自己的血量瞬间清零 → 立即死亡。
  * 打庄家   → 庄家的血量瞬间清零 → 立即赢下本回合。
  * 美术资源零改动：黑弹是运行时把原版“红色实弹”的材质复制并调暗成黑色，
    没有新增/修改任何贴图、音效、模型文件。

【出现规则】
  * 每回合最多 1 发黑弹。
  * 只有该回合同时存在红弹与蓝弹时才可能追加，因此：
        P(黑) = 0.5/(N+1) < P(红)、P(蓝)
    黑弹出现概率恒低于红弹与蓝弹。
  * 第一回合（教学回合）不出现。
  * 出现时播报示例："2 LIVE ROUNDS. 3 BLANKS.  +1 BLACK"

【只在单人模式生效】
  只修改单机脚本 scripts/*.gd；多人模式用的是 multiplayer/scripts/ 另一套脚本，
  完全未改动，联机不会出现黑弹。

--------------------------------------------------------------------
【安装】—— 分享给朋友时对方也是这样做
--------------------------------------------------------------------
  1. 先完全退出游戏（游戏在运行会占用 exe，导致无法写入）。
  2. 解压后双击 install.bat。
     - 脚本会自动在 Steam 库中查找 Buckshot Roulette（读取注册表与
       libraryfolders.vdf，支持多个 Steam 库 / 非 C 盘）。
     - 如果自动找不到，把“包含 Buckshot Roulette.exe 的文件夹”拖到
       install.bat 上，或命令行执行：
           install.bat "D:\Steam\steamapps\common\Buckshot Roulette\Buckshot Roulette_windows"
  3. 看到 "Installed 7 script(s) ... Verified OK." 即成功，进游戏即可。

  如果失败：
   - "access denied" → 右键 install.bat → 以管理员身份运行。
   - "game is running" → 彻底退出游戏（含后台进程）后重试。
   - "different game version" → 说明游戏版本不是 v2.2.0.6，需要对应版本。
   - 杀毒软件拦截 → 允许即可（模组会写入 exe，可能被启发式误报）。
   - 从网上下载的压缩包可能被 Windows 标记为“来自网络”，
     右键 zip → 属性 → 勾选“解除锁定”→ 再解压。

【卸载】
  双击 uninstall.bat（读取安装时生成的 install_backup.json 还原原始脚本）。
  也可在 Steam 中“验证游戏文件完整性”，效果一样。
  卸载脚本会先校验当前文件确实是本模组改过的版本，版本不符会拒绝执行，
  不会把别的版本改坏。

【重复安装 / 游戏更新】
  * 重复运行 install.bat 是安全的：已安装会提示 "already installed"。
  * 游戏更新（Steam 覆盖 exe）后，模组会失效，重新运行 install.bat 即可。
  * 如果游戏更新后版本号变了，安装器会拒绝安装并提示版本不符，
    此时需要等待对应版本的模组。

【文件说明】
  install.bat          一键安装（自动找游戏 / 支持拖拽路径）
  uninstall.bat        一键卸载
  patch.ps1            补丁程序（用 Windows 自带 PowerShell，无需 Python）
  mod\scripts\*.gd     7 个被修改的 GDScript 脚本
  install_backup.json  安装时自动生成，卸载用（删除后仍可用 Steam 验证还原）

【原理】
  Buckshot Roulette 使用 Godot 4.1.1，全部资源（含 GDScript 源码）打包在
  “Buckshot Roulette.exe” 内嵌的 PCK 里（PE 节名 pck）。
  安装器解析 PCK 文件表，把 7 个脚本替换进去：
    · 新脚本更小 → 原地覆盖；
    · 新脚本更大 → 追加到 exe 末尾并改写该文件的 offset/size/md5。
  原有数据完全不移动；卸载只把文件表项恢复为原始值。

【注意】
  * 这是修改游戏 exe 的模组；Steam“验证游戏文件完整性”会还原官方版本。
  * 仅单人使用；如平台有成就校验，模组可能影响成就。
  * 与其它修改同一批脚本的模组可能冲突（后安装者生效）。
